# Fruit Tree Target-Oriented Variable-Rate Spraying Robot

Embedded control project for a fruit-tree target-oriented variable-rate spraying robot. The computer-vision code is not included.

## Project notes

Open Project.uvprojx in Keil. The project contains Control, Core, Hardware, System and User directories. Start spraying-device tests unloaded, with clean water and limited speed.

## Quick start

```bash
git clone https://github.com/user1745/Fruit_Tree_Target-Oriented_Variable-Rate_Spraying_Robot.git
cd Fruit_Tree_Target-Oriented_Variable-Rate_Spraying_Robot
```
